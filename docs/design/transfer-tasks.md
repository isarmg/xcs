# 传输任务页面

主导航的“传输任务”集中显示本次登录会话的上传记录。文件页只保留概况及跳转入口；切换文件、详情、历史或传输页面不会重置队列。

## 状态与操作

| 状态 | 含义 |
| --- | --- |
| 等待上传 | 已进入当前队列，尚未开始发送 |
| 正在上传 | 正在准备、发送或等待服务器接受文件 |
| 正在保存 | 文件传输完成，正在封存或等待提交确认 |
| 正在确认保存结果 | 结果未知，只查询原操作 ID，不重复上传 |
| 已保存 | 收到匹配原操作的成功回执 |
| 已保存，保护不足 | 已发布，但回执明确指出保护不足 |
| 未保存 | 预检、上传或保存确定失败，或前项未知使本项没有开始 |

页面提供状态筛选、计数、文件名、目标、大小、开始及结束时间、错误和请求编号。尚未发送保存操作的编号明确标为本地任务编号。没有真实逐字节进度来源时只显示阶段，不生成估算百分比。

“查询原操作”与自动轮询共用实现，只允许查询结果未知且未在查询中的原 ID。未知结果使后续队列停止；原文件选择已经释放的未开始项明确要求重新选择，不能继续显示虚假的等待状态。

“清除已完成”只移除成功或保护不足的客户端记录，不删除服务器文件、版本、工作区或操作。失败及未确认记录不会被该按钮移除。

## 会话与目标边界

- 队列由 `State.transfers` 唯一拥有，不属于某次目录浏览结果。
- 记录仅存在于当前页面会话内；退出、重载或切换账号后清空，不宣称跨重启持久历史。服务端文件和发布历史不因此删除。
- 文件选择开始时固定会话、目录和分支上下文；取消或迟到选择不能被重定向到新目录。
- 本地预检失败也留下任务记录，但不会创建服务器工作区或提交操作。替换文件的失败记录保留实际目标及分支，不能误用源文件名推断目标。
- 已上传字节不等于已保存。HTTP 传输错误、提交结果未知与已发布后的保护状态分别处理。

## 六平台页面预览

共享界面供 Linux、Windows、macOS、Android、iOS 和 iPadOS 宿主使用。传输布局沿用公共字体、行高、轮廓和焦点规则；长名称换行，手机元数据单列，壳与正文尊重安全区。

CI 可通过 `ZXS_PLATFORM_PREVIEWS` 输出六种视口 PNG 和来源记录。页面使用真实生产 WASM、真实临时服务及合成测试文件：正常上传产生已保存记录，超限文件触发真实本地错误，延迟原始上传响应交付以捕获进行中状态；不注入假任务或假成功回执。

这些 PNG 是真实 Chrome 渲染的共享界面尺寸预览，不是六种操作系统或原生 WebView 的实机截图。宿主编译、原生交互、移动文件提供方和真机验收范围见[平台矩阵](app-platform-matrix.md)。
