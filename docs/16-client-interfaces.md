Web 是统一的浏览器用户界面，文件操作及获授权的高级功能均通过 HTTPS 业务 API 提供，布局适配桌面和移动浏览器。独立 SMB 入口由 Samba 和服务端桥接提供。CLI 仅提供本机服务、初始化、必要管理和离线救援，不再作为远程客户端。

## 16.1 用户界面

| 区域 | 展示内容 | 必要约束 |
| --- | --- | --- |
| 连接与磁盘入口 | 服务器身份、在线状态、各独立磁盘目录 | 未认证不泄露私有内容；磁盘不作为分支选择器 |
| 文件列表 | 当前磁盘、面包屑、文件夹、文件、大小、搜索和常用动作 | 新建文件夹、重命名、删除及元数据管理围绕当前目录；不提供文件上传、下载、正文预览；副本盘明确只读 |
| 文件详情 | 所选文件容器、备注、分支、节点历史、标签、文件分支合并和保存状态 | 分支绑定该文件；合并显式确认参与head、结果与归属，规则见[补充说明](design/file-merge-tags-backup.md)；版本树与正文状态仍可查看，正文读写不通过 Web |
| 目录分支 | 稳定命名分支和不可变子树 | 创建引用共享文件分支，修改/子项选择只追加子树；默认根组合可由有写权限用户选择并供 SMB 读取 |
| 状态 | 简单 CPU 使用率、内存用量和各磁盘容量/在线状态 | 只显示真实采样；未知值显示不可用，不伪造零值或趋势 |
| 历史记录 | 文件路径、动作、作者、顺序和可用时间 | 不拿传输任务或硬盘列表代替文件操作历史；旧记录无时间时明确未知 |
| 高级历史工具 | 历史域、旧MergeLink关系线、拆分来源、PURGED节点 | 不在默认文件页面展示低层仓库/计划表单；旧关系标记与文件详情的FileBranchMerge分别处理，目录分支合并待用户确认 |
| 提交历史 | 版本父节点、合并关系、作者、时间、操作摘要、目录差异 | 内容已删仍显示节点；时间不代替日志顺序 |
| 管理与清除 | 来源映射树、盘位/换盘、容量来源占比、清除和拆分 | 用户审查固定目标及迁移范围；均衡只建议不自行改路由 |
| 恢复 | 文件/目录恢复预览、容量和名称冲突 | 历史保存登记新分支，仅实际写入产生 FULL，其余继承父版本，不覆盖主分支 |
| 错误中心 | 原操作、错误码、可恢复状态和请求 ID | 不只弹一次短暂通知后丢失错误 |

## 16.2 文档打开方式

Web 打开文件详情只展示元数据、分支与版本树，不读取或预览正文，不提供上传、下载或“写入当前分支”入口。SMB 按标准协议提供文件读写，关联编辑器与文件交接由 SMB 客户端处理，并按实际客户端组合验收。

文件正文通过 SMB 或受控 HTTP API 读写；这些接口不因 Web 入口移除而改变。不能绕过权限或改成从物理盘直接共享路径。项目不提供原生 App。

## 16.3 本机维护入口

当前命令以 [本机维护说明](components/admin.md) 和 `zxs --help` 为准：

- 服务与初始化：`config-template`、`init`、`init-auth`、`register-disk`、`serve`。
- 离线救援：系统目录恢复、单盘检查与救援导出、降级恢复及独立历史包。
- 必要本机管理：账户、仓库、SMB 绑定、策略、状态查询和计划操作；打开本地池前先停服。

远程客户端与普通文件传输入口已移除；不能把仍保留的 HTTP API 或客户端库误认为产品 CLI。Web 尚未覆盖全部管理能力，因此本机管理命令暂时保留。线上换盘和拓扑迁移也不因曾有目标接口示例而视为已实现。内容清除和树拆分仍须先审查预览计划，再携带摘要执行。结构化结果明确区分事务发布、保护及恢复状态。
