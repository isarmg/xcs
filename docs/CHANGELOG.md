- 收敛服务初始化、错误边界和前端状态，修复 Bearer 方案大小写，磁盘列表改为校验型数据。
- 修正现行文档漂移、页脚与上手导航，保留原始来源及历史证据。采用与未采用部分见[本轮说明](reports/two-review-improvements-20261023.md)。

## 2026-10-20：Rust 源码自主维护与 Web／SMB 范围

- 用户入口收敛为 Web 与独立 Samba 桥接；内部管理 CLI 保留，原生 App、宿主、桥接、专用测试及依赖退出正式构建。
- 390 个 registry 包及 15 个 fork／提取组件纳入仓库，覆盖 11 个工作区、13 个工作区与目标组合；统一维护来源、许可、修改、角色、features 和逐文件回执，完整归档离线重导入通过。
- 新增 Web 逐键响应式快照、固定 Unicode 命名流水线和精简本地绑定器，并完成对应回归、正式 Web／真实浏览器及缓存 Samba SDK 检查。
- 具体计数、WASM 摘要、扫描边界、仍 OPEN 的三项许可通知复核及已通过的离线 release 构建见[本轮报告](reports/rust-source-autonomy-20261020.md)。本轮未提交、推送、部署或发布。
