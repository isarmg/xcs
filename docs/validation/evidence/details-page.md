# 独立详情页验收

本目录保留详情页历次布局检查。当前 G4 曲线、行比例及字号已更新，最新规则和验收见 [G4 记录](apple-g4.md)；下面的 14px 字号、14px 角范围和旧间距数字属于此前阶段。

详情作为顶栏中的独立菜单页面展示，文件列表不再渲染右侧详情栏。

真实浏览器验收覆盖中文、英文与手机、桌面宽度：文件夹详情、文件版本及备注、返回原目录、跨菜单保留选择、刷新、打开并取消编辑表单、文本预览与下载。文件列表的表头、单元格、文件名和操作文字统一为正文大小并垂直居中，文件夹和文件使用不同轮廓的图标；表格顶部紧凑，悬停背景覆盖整行左右。列表操作列只保留“详情”，目录分支操作位于目录工具栏或文件夹详情。测试不会提交改名、删除、备注或分支操作。

结果与截图见本目录的 `result.json` 及 PNG 文件。Rust 单元测试同时覆盖重命名后的选择保留、条目移除后的历史与预览请求失效，以及异步元数据更新时的控件保持。

表头和文件行统一为 36px，字号保持 14px；文件名单行省略，并可悬停查看完整名称。验收结果记录每一行的实际高度。

硬盘入口使用相同的列表组件，按行显示 P01、B01、C01 的访问权限和可用空间。选择框及其下拉选项也统一为 36px；详情空态提示使用相同的单行最小高度。

分支创建与按名称切换目录分支均使用原位下划线输入；Enter 提交，空白、失焦或 Escape 取消。业务页面采用较小轮廓，登录页保留原轮廓，并按旧版卡片宽度比例统一登录表单字号。真实分支写入使用独立临时池验证，见 `../inline-branch-real/`。

最终业务轮廓统一采用下拉选择框的 14px，面板、通知、对话框共用控件轮廓变量；列表外框采用与选择框一致的 1px 灰边，搜索框也为 36px 高。登录页保留原有轮廓，错误状态允许卡片按内容增高，保证恢复后的较大文字不被裁切。

单行内容的横向起点按字盒中心计算，不再以圆角结束位置或固定 26px 留白作为起点：`(行高 - 字盒大小) / 2`。36px 行高、14px 字号时，字盒左边距为 11px；带 1px 自身边框的搜索框、下拉触发器使用 10px 内边距。下拉选项、业务空态及加载提示和表格每个文字单元格使用同一公式；提示的多行内容可自然增高。带前导图标的首列以 17.5px 图标盒计算 9.25px 起点，图标之后保留正常文字间隔。44px 普通输入框的字盒左边距为 15px、内边距为 14px。日期裸输入、分支下划线输入、备注多行输入及登录页面保持各自布局，登录轮廓的安全留白仍为 26px。

列表最后一行不绘制底部分隔线，由 1px 外框单独形成底边，避免两条灰线叠加。横向滚动仍使用 `overflow-x: auto`，仅在表格确实超宽时出现。文字几何实测见 `text-geometry-result.json`，空态见 `empty-inset-result.json`，底边及滚动尺寸诊断见 `list-footer-before.json`，修后实际服务验收见 `list-footer-after-fix.json`，覆盖中英文、390px 与 1440px 宽度。
