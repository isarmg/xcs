此前记录称：在 Linux x86_64、Rust 1.99.0、官方 Samba 4.23.0 / VFS 51 上，使用本项目 release 模块、本地真实核心开发池和官方 `smbclient`，连接限制在 `127.0.0.1:14445`。

历史清单曾引用 `result.json`、`sdk-tests.txt`、`testparm.txt`、`module-protocol-close.txt` 和 `client.txt`。这些原始文件当前均不可用，以下仅保留当时文档所述结果，不能当作本轮重跑或当前可复核的实测证据：

- SDK 单元测试当时为 4 项，包括事件循环/取消、路径隔离和失败文件名查询保留原指针。
- `testparm` 当时退出 0，保留私有目录权限浏览警告。
- 文档报告实际加载 `zxs.so`、协商 `SMB3_11`、CLOSE 返回 `NT_STATUS_OK`。
- 文档报告新文件、3407872 字节往返、43 字节覆盖、大小写改名和折叠打开，下载内容比较及 SHA-256 一致。
