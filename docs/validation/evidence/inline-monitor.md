# 原位编辑与状态监测检查

2026-10-19。本轮要求：短文本编辑最多 128 个 UTF-8 字节，采用原位下划线输入；状态卡显示顶部实时值、下方真实历史图，支持 1min/30min/1h/24h/1month 范围，统一 3:2，桌面固定四列、手机一列；菜单及文件工具行沿用紧凑列表留白。

## 已执行检查

- Web 单元测试 56 项通过（共享 Runtime 26、应用 30）：UTF-8 128/129 边界、备注清空与取消区别、旧备注完整显示、未读取到备注时不能用空值编辑、范围切换过期响应保护、缺测断线、真实零功耗点、短图坐标轴布局及原有组件回归。
- 文件 metadata HTTP 集成通过：文件与版本两个接口的 128/129 字节、中文多字节、控制字符、清空、权限、幂等、持久化及改名后下载。
- 监测后端 17 项单测和 3 项 HTTP/路由集成通过：真实采样、权限、后台独立采样且业务发布序列不变、31 天缓存恢复和边界、传感器归属及计数回绕、每指标有效计数、u128 容量精度、新根目录初始化、普通缓存 I/O 失败内存降级。
- 契约校验通过：20 个已覆盖路径、31 个向量、519 个文档链接；5 项契约单测通过。OpenAPI 同步新备注限制、功耗字段及监测历史接口，并保留读取旧备注的兼容边界。
- CSS 源码夹具 1920/1440/800/690/390/320 六种宽度通过：9 卡均 3:2、固定列宽、末卡不拉伸、手机单列、图表空间、36px/14.4px 原位输入和工具行、无页面横向溢出。

最终资源验证通过：[14 份 CSS/WASM 的逐字节比对与严格 CSP 记录](../../../tests/evidence/inline-monitor/asset-result.json)。实际浏览器结果见下方；业务写入均在浏览器拦截，不修改用户文件。

功耗仅来自可读的真实硬件传感器；虚拟环境与开发模拟盘不伪造功耗。监测数据源、缓存与权限边界见[后端说明](../../components/server/src/telemetry.md)。

- 28 个页面状态共记录 1234 个字体测量、548 个实际绘制的 G4 轮廓；无旧字号，最大物理误差约 0.00934px，小于 0.02px 容差。无页面异常、CSP 违规或意外控制台错误；控制台中的 401 为初次未登录恢复，400/503 为上述主动拦截测试。WASM 均以 `application/wasm` 成功加载。5 个独立测试会话均已注销，服务保持运行。

## 短图专项与证据保留

初次验收发现正常 769px 窗口下，四列卡片内最大值与零刻度发生重叠。修复后图高不足 42px 只显示最大值文字、保留零网格线；图高不足 70px 省略时间轴文字，范围仍在工具栏显示；字体保持 14.4px。最终在同一浏览器会话验证 800／769／1440／390px 正常窗口，全部无刻度重叠、无溢出。没有执行浏览器缩放或异常大字体测试，也没有新增相关补偿。
