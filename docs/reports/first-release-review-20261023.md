## 已实施的修复

### 发行与安装材料

- 两份归档均包含实际运维文档引用的 `deploy/systemd/zxs.service`，缺失或不安全输入在打包前拒绝。
- 归档 UID/GID 规范为数值 0，文件和目录权限按安装所需读／执行位规范化，避免私有构建 umask 让服务账户无法读取资源。
- 组装前要求恰好两份非空普通归档，拒绝额外隐藏文件、目录、符号链接及版本路径注入，之后才写安装说明、构建身份和摘要。
- 安装文档说明服务路径替换、同版本 Web 切换、正常停服及不可盲目降级边界；发行正文以中文为主体。
- 普通 CI 在解压归档与浏览器验收通过后组装并留存 `installation-candidate-linux-web`，不是公开 Release，也不证明其他并行门禁通过。

### 存储内容与复制边界

- 同步内容读取与导出保留完整校验通过的文件描述符并归零偏移，不再校验路径后重新打开另一个 inode。
- 校验和接口绑定实际返回字节的摘要；正文校验补充尾部与最终长度检查；工作区读取同时核对声明长度与摘要。
- 局部写入先有界复制、验证临时副本的原始长度和摘要，再应用修改，不能把损坏的未修改部分重新确认成合法内容。
- 批量复制与历史拆分构建新版本时，核对原版长度和摘要后才更改候选状态，避免路径替换被重新封存。

这些约束针对已确认的检查／使用窗口和内容绑定，不承诺阻止拥有同一系统账户权限的程序在验证完成后任意原地改写文件。数据目录和只读载荷仍须按部署要求隔离。

### 管理认证、SMB 与 Web

- 认证文件锁复用平台私有目录和锁原语，拒绝符号链接、多链接及不安全权限，凭据读取使用持有描述符的有界读取，不在检查路径后无界读取。相对路径锚定为绝对路径，已有不安全目录不自动 chmod。
- SMB 成功 Open 回复在共享连接锁内验证完整结构；无法接管远端句柄时关闭共享会话并释放收到的描述符，不继续复用半完成状态。
- SMB 帧正文使用可检测控制信息截断的接收方式，拒绝正文附带描述符；回归覆盖重复 FD、控制缓冲区溢出及拒绝路径的 FD 释放。
- SMB 只读句柄的同步／异步读取按已确认逻辑长度裁剪，文件状态也报告该长度，不暴露验证后追加的尾部；可写工作区保留动态长度语义。真实 VFS 调用回归须由固定 SDK 的远程验收执行。
- 改密遇到网络错误、服务端错误或无效成功确认时，Web 保留结果未知围栏，禁止自动或重复改密，并给出退出后核实密码的说明；明确拒绝仍可纠正重试。

Web 的 ResizeObserver 重新检查未获得足以证明现有生命周期缺陷的证据，因此没有进行推测性改写。未修改 G4 转角、增加文件内容传输或恢复原生 App。

## 依赖及分发资料

当前根锁文件为 239 个包，无 registry/git 源码解析边；来源清单为 221 个活动所有者、107 项退役和 2 项替代历史，Foundation 的物理目录数仍为 219。合成安全审计按实际保留来源匹配 298 个上游身份，不能用包合并后的数量代替漏洞匹配范围。

原生 C 工具链门禁过去直接在源码包路径运行独立 Cargo 测试，运行期间会短暂生成子锁文件，可能与并行来源检查冲突。现将相同源码、外置测试和必要文档复制到独立临时工作区，保持原 manifest 与相对路径，不在源码树生成锁文件；特别保留 `cc/src/target` 这个真实源码模块，不把同名源码目录误当缓存过滤。

许可资料重新核对区分了退役的 `convert_case_extras`、`drain_filter_polyfill` 与仍进入 Web 的 `erased`。后者的官方固定发布包与提交仍未提供独立许可／版权文件，保留为首发前需人工复核的资料项，见[集中合规说明](../../compliance/README.md)。没有伪造版权信息或覆盖不可变来源收据。
