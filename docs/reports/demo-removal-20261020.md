# 演示代码清理（2026-10-20）

[报告索引](README.md) · [当前结构](../monorepo.md) · [分支业务规则](../design/branch-system-logic.md)

本轮按要求移除独立演示程序及其附属构建、验证和展示入口，产品继续提供 Web 与 SMB，服务端、存储引擎和运维工具保持现有职责。

- 删除 `examples/branch-system` 的内存演示模型、交互页面、静态图生成器、只读预览服务和浏览器脚本，共 104 个文件、5,659,321 字节，并移除独立生成目录。
- 清理 40 个基础包中的 106 个独立演示文件，共 215,355 源码字节；另从 `leb128` 清单删除 62 字节的演示二进制目标声明，没有修改库实现。
- 删除对应工作区成员、来源解析入口、CI／Release 的演示测试任务和 WASM 质量选择；质量门禁只检查正式 `web-app` 的 WASM 构建。
- 删除浏览器宣传素材采集及截图时额外创建展示文件的逻辑。保留真实产品回归、普通截图与响应式视口检查；失败诊断统一输出到 `artifacts/browser-smoke/diagnostics`。
- 删除三份演示手册、当前导航与专用忽略规则，收紧文档链接检查至正式说明和真实业务验证目录。历史报告保留执行时点的记录，并注明演示已经移除，修复指向已删除演示材料的链接。
- 清除 `build/branch-demo` 及 5 个过时的直接演示构建产物；后者共 18,430,527 字节。共享 Cargo 编译缓存继续保留。

工作区从 21 个成员减至 20 个，根锁解析包从 359 个减至 358 个，外部 registry／Git 来源仍为 0。登记解析组合从八个减至七个；演示没有独占基础依赖，活动上游源码仍为 340 个、已退役来源 63 个、原始身份 405 个。

分支、合并、标签和备份属于实际存储业务，相关实现、专业规则及业务回归继续保留。供编译文档、真实测试或性能检查使用的 672 个示例／性能文件均保留并核对字节不变，其中 540 个基准文件未改。原始上游文档、许可证和 provenance 仍集中保留。

本轮已验证：CI Python **32 项通过**；契约工具 **17 项 Rust 测试通过**，包含忽略规则和真实源码导出；契约命令检查 **1,231 个本地链接、71 个语义向量和 30 条 API 路径通过**。3 个缺失目标属于按规则忽略的本地生成验证附件，已单独统计。相关 Shell 语法、格式及全仓 `git diff --check` 通过。CI 增加精确回归，旧演示测试入口必须在调用任何工具前返回错误，正式 WASM 编排只选择 `web-app`。
