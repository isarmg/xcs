## 已落地行为

| 操作 | 实际行为 |
| --- | --- |
| 创建文件分支 | 只登记冻结来源，不建空正文；读取父版本，首次实际保存生成独立 FULL，即使内容相同或为空 |
| 创建目录分支 | 复用父子树及其公共文件节点，不批量创建文件分支；写到哪个继承文件，才为哪个文件创建公开分支 |
| 后续修改 | 追加不可变目录子树，保留命名分支的 ID 和名称；逐层更新必要祖先，复用未改内容 |
| 切换目录 | 恢复完整成员、名称、层级和具体版本；子目录选择直接引用其冻结子树 |
| 显式选择文件分支 | 将该逻辑路径的后续写入指向所选公开分支；继承与显式选择有独立状态，同节点首次显式选择仍有效，重复相同选择不增加子树 |
| SMB 默认入口 | 用户可选择根目录组合；新路径操作使用新入口，旧读取固定版本，相关旧写会话冲突并保留暂存内容 |
| 跨目录移动 | 源选中分支移除引用并停止跟踪，目标选中分支新增引用接管；保留文件身份、实际搬移版本容器，未选分支保留原路径和版本 |
| 同文件的多个逻辑路径 | 每个路径保存独立的公开分支、继承意图及选择代数；a 的旧引用和 b 的新版本能同时显示，写入其中之一不推进另一条引用 |
| 批量复制 | 创建独立文件身份和真实初始 FULL；同一实际目标目录／名称的多个目标分支共享一次新复制，来源只读 |
| 批量删除／改名 | 只修改明确选中的目录分支；历史及未选引用可读。文件／文件夹改名还为每个受影响文件增加路径节点，复用正文；分支标签改名不生成节点或目录子树 |
| 原子与重试 | 每项携带源／目标分支 ID、依据子树、源路径和条目 ID；冲突整批失败，同一操作 ID 重试返回同一回执 |
| 文件分支合并 | 明确输入分支头、任意结果节点和归属；选择输入头则复用，否则仅增合并元数据节点；保留完整来源及无环连线，其他输入转只读别名；目录分支合并待确认，不提供写入口 |
| 合并的目录同步 | 只更新引用参与文件分支的命名目录当前视图；冻结旧子目录引用按原组合派生，不跟随子目录现有 HEAD；旧树、未参与分支及独立别名保持原样 |
| 节点标签 | 每个节点最多 16 项、每项最多 128 UTF-8 字节；子节点继承，增删标签生成复用正文的元数据子节点；历史标签不回退较新正文，批量预检原子发布 |
| 备份路径 | 每个备份盘独立用户前缀，按稳定文件身份绑定份数及路径；设置时补足所有可用版本，主盘移动不重设；原版本和正文证明保留，新保护发布按候选归档 |
| Web | 文件／目录多选、逐条分支映射、页面内审阅和下划线改名；冲突保留输入，不确定结果查询原操作，避免重复复制；父下子上、等粗正交圆角箭头 |

分支名称和备注写入最多 128 UTF-8 字节。自动文件分支名使用来源目录分支名及唯一后缀，截断保持 UTF-8 完整；文件、目录的公开分支标签均可原位改名。旧内容和证明保持原身份。

## 代码结构

| 位置 | 职责 |
| --- | --- |
| `crates/xcs-contract/src/model.rs` | 不可变目录子树、精确子目录引用、按路径的 `FileContext` 和批量请求 |
| `crates/xcs-core/src/business/directory.rs` | 组合恢复、继承首写、祖先子树及路径上下文 |
| `crates/xcs-core/src/business/batch.rs` | 冻结依据校验、显式映射、复制身份、整批发布及回执 |
| `crates/xcs-core/src/business/file.rs`、`file_metadata.rs`、`file_paths.rs` | 公共文件分支、定向内容发布、分支名称和不可变路径节点 |
| `crates/xcs-core/src/business/file_nodes.rs`、`file_merges.rs`、`file_tags.rs`、`file_publication.rs` | 公共节点解析、标签继承、合并来源与只读别名、按精确引用统一发布 |
| `crates/xcs-core/src/protection/backup_paths.rs` | 稳定策略范围、每盘前缀、子策略优先、既有正文回填和代数检查 |
| `crates/xcs-core/src/business/workspace.rs` | 工作区范围、暂存、选择冲突和自己的首写后续保存 |
| `crates/xcs-core/src/container_storage.rs` | 单一真实容器、路径迁移、旧格式解析及缓存投影 |
| `crates/xcs-core/src/history_package.rs`、`maintenance.rs` | 历史包、引用验证、恢复及冻结正文保留 |
| `crates/xcs-server/src/engine_backend/file_manager.rs` | 授权、路径上下文、批量 API 和操作审计 |
| `crates/xcs-server/src/engine_backend/file_manager/backup_namespace.rs` | 按备份逻辑前缀的只读浏览、授权过滤、固定正文和历史容器，不反向猜主盘路径 |
| `web/src/files/batch/` | 草稿、纯请求校验、请求生命周期和显示分离 |

路径、标签及合并元数据节点与正文版本分开存储，历史树统一显示；节点引用真实正文，不创建假正文版本，后续写入通过节点父边衔接历史，原正文的内容证明不重写。节点备注独立保存，最多 128 UTF-8 字节。标签校验和容量上限统一放在 `xcs-contract`，核心、历史包读取和 Web 共用。

目录与文件的旧单身份映射仅保留为兼容缓存；多个路径的选择以 `FileContext` 为准。历史快照保存自己的路径上下文，恢复时不追踪公共分支后来移动的 HEAD。

容器由稳定文件身份定位，当前规范路径记录在 `file_locations`。现代正文实际位于 `histories/<history>/file-containers/<file>/namespace/<目录>/<当前名称>/versions/`。改名移动该容器，不复制正文；旧逻辑路径按稳定身份解析。旧格式正文也能迁入当前容器，版本清单和发布证明不重写。

## 使用与验证边界

文件页勾选条目，选择移动／复制／删除／重命名，随后明确勾选源分支，并为需要目标的操作逐条选择目标目录和目标分支。旧命名空间尚无目录组合时，界面提供显式登记基线，读取列表不隐式写入记录。

批量事务的当前边界为同一主盘上的同一托管仓库／历史域；跨历史树操作不伪装为保留身份的移动。一个真实文件在同一次批量操作中的物理去向必须唯一，冲突的映射整批拒绝。含目录组合或文件路径节点的历史域尚不支持独立树拆分，当前明确拒绝该操作，防止丢失引用；普通历史域拆分保持原有行为。未选分支的逻辑路径可以与规范位置不同。

[验收材料与执行结果](../../tests/evidence/branch-operations/README.md)分别列出 Rust、HTTP、SMB SDK、实际 WASM 浏览器和本地服务的证据。临时目录的三成员测试不是三块物理设备的断电验收；Unix 描述符测试不是部署 smbd 和六平台设备验收。

本地预览已使用包含文件合并、标签与备份浏览修正的最终候选更新并恢复，入口为 [http://127.0.0.1:7400](http://127.0.0.1:7400)。[最新服务核验](../../tests/evidence/merge-tags-backup/served-assets.json)记录 HTTP 200、进程摘要、严格 CSP、实际静态资源和构建输入匹配；此前记录保留为历史验收。
