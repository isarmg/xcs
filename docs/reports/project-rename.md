# ZXS 项目命名统一

本轮将项目代码、crate、命令、环境变量、配置、服务、HTTP 标识、桌面应用标识、样式与资源路径统一为 ZXS / zxs。没有提供旧名称别名或兼容入口。用途隔离摘要前缀、认证 CSRF 域和二进制格式 magic 同步更新；固定向量按新规范重算，原始内容摘要不变。旧版本材料不是新版本可直接读取的兼容格式，不要把新程序直接指向旧数据目录。

历史记录的说明文字和可执行示例使用当前命名，但其中的日期、测量值、截图、已记录结果和提交标识仍属于当时的版本，不代表本次重新运行后的结果。性能原始 JSON 未修改。复现历史版本时必须使用该提交的原始源码与工具，不要将新路径机械套用到旧提交。

## 本轮源码验证

2026-10-20，本地 Rust 1.99.0：核心恢复与数据完整性测试、认证、契约、客户端、CLI、Web、应用桥接、SMB 协议及构建工具测试通过；Web 的 wasm32 编译通过。契约检查器通过 52 个 schema/语义样例、3 个规范摘要向量、2 个二进制清单向量及文档链接检查。摘要向量保持固定期望值，并检查新用途前缀与实际编码器一致；没有删除或放宽断言。

完整工作区运行受到执行环境的特殊文件/Unix socket 系统调用权限限制：平台的两个安全测试及服务端的一个 socket 取消测试返回 EPERM。其余服务端测试（68 个单元、26 个 HTTP 集成、1 个遥测集成）通过；受限测试未改动，仍需在具备相应权限的 CI/宿主运行。桌面宿主、生产 WASM 打包和真实浏览器截图以新提交的 CI 结果为准，本地编译不能替代它们。
