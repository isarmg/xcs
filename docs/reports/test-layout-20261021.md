- foundation（不含单独处理的 ring）：3,778 个外置文件、274 个来源包，涵盖 1,133 个完整模块、637 个独立测试函数、一个测试专用宏和 2,007 个原有测试/模块/夹具文件。原有 154 组休眠测试配置没有被自动激活。
- ring：保留 15 个集成目标及完整固定材料，外置测试通过新的认证映射继续接受原历史验证器校验。
- 历史验证：27 个冻结文件逐字节保留；26 个历史脚本和 5 个运行器测试仍纳入静态检查。

foundation 源码中剩余的 43 个词法测试标记位于 13 个文件，属于生产生成宏或已有导出的下游测试/代码生成 API，不是可独立抽离的测试函数。生产结构中必要的条件字段及 hook 保持原位。没有为目录整齐改变生产接口或删除用例。

## 独立核对

业务侧 208 个剩余 Rust 源文件，除测试模块接线及空白外生产内容不变；迁移夹具字节和字符串字面量保留。foundation 原源码与新源码加外置测试的词法测试标记数均为 18,170；该数字只用于守恒核对，不代表实际运行了这些休眠或生成测试。

初次迁移提交的上游来源覆盖为包内 6,981 个文件加外置 3,939 个测试文件，共 10,920 个当前文件。外置上游测试逻辑字节数为 40,630,177。整个根 `test/` 不含 Python 缓存时为 4,160 个文件、42,709,581 个逻辑字节。拆分可能增加文件数，这些数据不得当作删除了等量源码或性能提升。

初始分离证明采用压缩的可逆行差异，不复制完整来源档案；它绑定迁移前来源哈希，并检查当前文件与外置片段可以重建原视图。当前文件仍可在审阅后按正常流程更新；原始来源和历史证明不改写。
