## Logic and trust boundaries
- SMB Client serializes complete calls on a shared Unix FrameStream. Strict framed JSON has8MiB cap; one SCM_RIGHTS fd is owned immediately and CLOEXEC. Server auth/ACLs remain outside this slice.
- VFS main event loop owns Samba/talloc pointers; worker pool owns copied buffers, duplicated FDs, Arc RPC and completion state only. eventfd/tevent watcher owns its read fd; cancellation frees host state while worker retains shared completion and wake fd.
- VFS validates share-relative paths, serializes per-open I/O and refuses lower-layer writes/links/offload that bypass core.
- SDK build pins4.23.0 / VFS51, requires generated config.h and bindgen of actual headers.
- Web builder takes exclusive lock, hashes sources before/after compile, verifies wasm-bindgen version, creates deterministic gzip/manifests and stages old/new dist directory renames.
- Contract checker remains offline, checks schema/OpenAPI references, semantic vectors, examples and local documentation links; Unicode builder verifies fixed input SHA256 and byte-exact generated output.

## Findings and changes
1. Client previously retained FrameStream after partial send/receive or malformed response; next call could accept a leftover success as a different request. Changed storage to Arc<Mutex<Option<FrameStream>>> and shutdown/take before releasing lock on exchange failure. All clones subsequently return NotConnected. Fully decoded business Error responses preserve the stream and errno diagnostics.
2. VFS close removed a raw-fd Open before locking its I/O mutex. A poisoned lock exited before close and removed it from free_context cleanup. Extracted close_opened, immediately wraps the uniquely owned fd in OwnedFd, preserving normal explicit close error reporting and cleaning every early return/unwind.
3. Web inventory treated all non-directories as fs::read inputs, so FIFO could block; roots themselves were not symlink checked. Centralized input_type/read_input normal-file checks across copy/inventory and explicit source files, reject special nodes before reading and reject directory-root symlinks.
4. No concrete async host-pointer escape/cancellation defect found in the reviewed worker/event ownership flow; did not change its ABI/lifecycle. No invented Unicode, contract-check or bootstrap issue.
