# 删除菜单页面标题

2026-10-18。此前通过 `visually-hidden` 裁切页面标题的方案已由直接删除源码节点的方案替代：文件、状态、历史记录和账户页的四个 `h1` 已移除。公共 `visually-hidden` 样式仍供搜索等其他元素使用。文件、状态和历史页的独立刷新工具行也已删除，改由顶部菜单栏提供当前页面的刷新按钮；账户页不显示刷新按钮。业务主区取消居中最大宽度限制，宽屏下继续使用窗口宽度，保留正常内容边距。

验收脚本 当时的临时测试目录或日志 检查四页 DOM 中均不存在 `h1` 和 `.zxs-page-toolbar`，三个业务页均只有一个刷新按钮且位于顶部菜单栏，账户页没有刷新按钮。另检查页面第一项内容前没有空行，菜单栏下无多余留白；在 2560、1920、1440、390、320px 五种宽度下检查无横向溢出，主区无最大宽度限制、左右外留白各不超过16px，业务区左右留白含其内边距各不超过20px（以可用布局宽度计算，扣除滚动条）。输出各页截图与 `menu-headings-result.json` 至本目录。过往隐藏方案的原始记录保留在 [contour-response](../contour-response/README.md)，不代表当前实现。


真实 Chromium 检查通过：四页×五种宽度共20组布局检查，页面无标题节点、无独立刷新行、无横向溢出。业务内容从菜单栏下直接开始，左右各16px；宽屏正文无居中留白。刷新请求分别命中磁盘列表、当前P01目录、状态及历史接口。状态卡片按实际数量自动分配列宽。Linux宿主重新嵌入本次资源并链接，未执行桌面或六平台发行验收。
