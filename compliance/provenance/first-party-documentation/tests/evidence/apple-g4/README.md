# G4 轮廓与行比例验收

本目录保留 G4 构造和历次比例验收。当前字号已更新为行高 2/5（36px 行为 14.4px、44px 控件为 17.6px）；全面检查见[界面一致性记录](../ui-consistency/README.md)。以下 1/3 字号结果属于此前阶段，半行圆角规则仍然适用。

2026-10-19。当前轮廓采用项目所有者提供的两份 HTML 原文中的 G4 构造，来源为[第一篇](https://zhuanlan.zhihu.com/p/709019955)与[第二篇](https://zhuanlan.zhihu.com/p/713026877)。曲率公式、积分误差界和项目参数见 [Runtime 说明](../../../web/runtime/README.md)。旧七次 Bézier 实现已删除，内部名称统一为 `zxs-g4`。

最终规则：36px 单行字号 12px，竖边上下两个圆角各占 18px，中间没有直线；44px 普通输入字号约 14.67px、角范围 22px，侧边同样没有直线。多行面板使用统一的 18px 角范围。文字和前导图标继续按方框中心等距对齐。登录保留此前字号和物理角范围，底层轮廓也使用 G4。

Rust Runtime 的 26 项测试通过，包含 G4 端点和圆弧接点、独立积分、导数、平行偏移、凸性、误差预算和缓存。WASM 目标检查和正式 Web 构建通过。实际浏览器将真实 SVG/裁切路径与独立 JavaScript 数值积分逐角对照，同时检查字号比例、边框、下拉菜单、各菜单页面及手机横向滚动；脚本只允许认证请求，不修改用户文件。

最终半行圆角版的中英文、390px/1440px 四场实测均通过，见 `final-half-corners-result.json`。36px 和 44px 单行的上下两角在侧边中点重合，左右直线段长度均为 0；多行面板复用 18px 的角范围。独立 G4 轮廓对照的最大偏差约 0.00934px，小于 0.02px 预算。旧三等分角与字号调整记录保留为历史，当前以半行圆角结果为准。放大轮廓示意见 `contour-comparison.png`。
