# XCS 文件存储系统

XCS 是面向独立硬盘管理的文件存储项目，由一台 Linux 服务端统一管理文件、历史版本和分层备份，提供 Web、CLI、原生 App 与独立 SMB 访问入口。

## 核心功能

- 文件管理：按磁盘浏览文件和目录，支持上传、下载、移动、改名及操作历史查看。
- 版本与分支：内容写入形成独立完整版本；文件分支先引用冻结父版本，首次写入才保存自己的内容。目录分支组合文件分支，并保留不可变目录历史。
- 合并与标签：显式选择文件分支的合并结果与归属，为版本节点添加可继承的标签。
- 备份与恢复：按用户指定的盘位和逐级来源保存完整副本，提供完整性校验、历史内容清除和离线恢复工具。

## 平台与架构

业务核心、客户端和界面使用 Rust 实现。Web 使用 WASM；原生 App 使用 Tauri 宿主，共享 Web 界面与客户端逻辑，面向 Linux、Windows、macOS、Android、iOS 和 iPadOS。App 通过业务 API 访问服务；SMB 通过 Samba 桥接接入同一存储核心。

项目持续开发中。现有自动化测试与平台构建覆盖部分实现；物理设备故障、原生设备交互和签名分发仍需专项验收。
